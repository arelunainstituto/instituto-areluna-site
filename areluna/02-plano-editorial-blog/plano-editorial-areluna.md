## Princípios

1. **Não duplicar conteúdo entre os 2 domínios.** Mesmo post pode existir nos 2, mas com **hreflang** (`pt-PT` ↔ `pt-BR`) e adaptações (sotaque, ortografia, NAP local). Sem hreflang = canibalização.
2. **Cada post serve um pilar + uma intenção de busca.**
3. **Cada post tem CTA estruturado** para uma das 3 LPs comerciais (alinhadores, facetas, implantes) ou para "Marcar avaliação".
4. **2 posts/mês** + 1 atualização de post antigo + 1 estudo de caso (antes/depois).
5. **Todo post tem:** focus keyword, title SEO ≤60 chars, meta description ≤155 chars, H1 com keyword, H2/H3 hierárquicos, alt em todas as imagens, schema Article + Author + (FAQPage se aplicável).

## Template de produção (cada post)

```
TÍTULO: <60 chars com focus keyword
SLUG: /blog/keyword-principal-cidade/
FOCUS KEYWORD: <expressão exata>
META DESCRIPTION: <155 chars + CTA>
H1: <usa focus keyword>
ESTRUTURA: Intro (gancho problema) → 3-5 H2 → FAQ (5 perguntas) → CTA
WORD COUNT MÍNIMO: 800 (satélite) / 1.800 (pillar)
SCHEMA: Article + Author + FAQPage (se tiver FAQ)
INTERLINKING: 2-3 links para outros posts + 1 para LP comercial
IMAGEM DESTACADA: 1200x630 + alt descritivo
IMAGENS INTERNAS: 2-4 + alt descritivo
CTA: bloco final padrão (ver §abaixo)
```

## Estrutura de URL e taxonomia

- **URL pattern:** `/blog/<slug-keyword>/` — sem data, sem ID.
- **Categorias** (selecionar 1 por post): `Reabilitação Oral`, `Estética Integrada`, `Implantes`, `Alinhadores`, `Facetas`, `Turismo Dentário`, `Casos Reais`.
- **Tags** (3-5 por post): livre, mas usar palavras-chave reais (`implante carga imediata`, `alinhadores invisíveis porto`, `facetas durabilidade`, etc).
- **Sidebar** (na listagem): Categorias + 5 posts mais recentes + CTA para avaliação.

## O que NÃO publicar
- Posts genéricos de "Top 10 dicas de higiene bucal" — não diferencia, baixo CTR comercial.
- Posts sem foto própria (banco de imagens despersonaliza).
- Posts sem nome de autor (anônimo perde autoridade E-E-A-T).
- Posts com FAQ schema sem FAQ visível na página (penalidade).
